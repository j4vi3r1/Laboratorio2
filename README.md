# Proyecto: Aplicación Web con CRUD y Docker

Este proyecto consiste en el despliegue de una aplicación web PHP con base de datos MySQL, orquestada mediante Docker Compose para garantizar un entorno de desarrollo consistente y persistencia de datos.

## Estructura del Proyecto
- `app/`: Contiene el código fuente de la aplicación (PHP).
- `docker-compose.yml`: Archivo de configuración para los servicios.
- `Dockerfile`: Definición de la imagen del servidor web.

## Requisitos Previos
- Docker instalado y configurado.
- Docker Compose.
